# Security policy

Please report vulnerabilities privately through GitHub:
[report a vulnerability](https://github.com/meerkat-events/meerkat/security/advisories/new).
Don't open a public issue for them.

Include what you found, how to reproduce it and which deployment it
affects, if you know. We aim to reply within a week.

Only the latest version on `master` and the deployed instances are
supported. The `@meerkat-events/react` package is covered too.
